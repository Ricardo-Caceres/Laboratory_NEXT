## 🎨 Module Standards

### Required Structure
ALL learning modules must use LeftPanel/RightPanel layout:

```typescript
import { LeftPanel } from '@/components/layout/LeftPanel';
import { RightPanel } from '@/components/layout/RightPanel';

export default function ModulePage() {
  return (
    <div className="flex flex-col lg:flex-row min-h-screen">
      <LeftPanel
        title="Your Module Title"
        description="**Markdown** formatted description"
        codeContent={[{
          filePath: 'example.tsx',
          content: `// Your code example`
        }]}
      />
      <RightPanel>
        {/* Interactive content or examples */}
      </RightPanel>
    </div>
  );
}
```

### Design Rules
- ❌ **NO gradients** - use solid colors
- ✅ **High contrast** - WCAG AA minimum  
- ✅ **Code in `<code>` components** - never plain tags
- ✅ **Responsive** - mobile-first
- ✅ **Consistent** - follow existing modules

### Color Palette
```
Background: white, slate-50
Text: slate-900 (headings), slate-700 (body), slate-600 (muted)
Borders: slate-200, slate-300
Primary: blue-600
Success: green-600
Warning: orange-600
Error: red-600
```
