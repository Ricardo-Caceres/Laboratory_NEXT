## 🎨 Principios Implementados

### SOLID
1. **Single Responsibility** - Componentes con una sola responsabilidad
2. **Open/Closed** - Extensible mediante props y composición
3. **Liskov Substitution** - Subtipos sustituibles
4. **Interface Segregation** - Interfaces específicas
5. **Dependency Inversion** - Dependencias abstractas

### Clean Code
- Nombres descriptivos y claros
- Funciones pequeñas (max 20 líneas)
- DRY (Don't Repeat Yourself)
- KISS (Keep It Simple)
- YAGNI (You Aren't Gonna Need It)

### Modern JavaScript
- Optional chaining (`?.`)
- Nullish coalescing (`??`)
- Async/await
- Destructuring
- Template literals
- Arrow functions
- ES Modules
