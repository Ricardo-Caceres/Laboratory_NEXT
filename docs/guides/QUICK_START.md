## 🔥 Interview Cheat Sheet

### Technical Questions
- **React**: Hooks lifecycle, reconciliation, virtual DOM
- **TypeScript**: Generics, utility types, type inference
- **Algorithms**: Time/space complexity, common patterns
- **System Design**: Scalability, load balancing, caching
- **Testing**: TDD, unit vs integration vs E2E

### Behavioral Questions
- **Leadership**: Use STAR framework (Situation, Task, Action, Result)
- **Conflict**: Show empathy, data-driven decisions
- **Communication**: Adapt to audience (exec vs engineer)
- **Growth**: Continuous learning, mentoring others
